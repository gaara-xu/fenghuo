# 烽火战国 2012 单机重制

面向内网单人存档的非 Flash 重制项目。前端使用 Vue 3 + TypeScript，服务端使用 Fastify，持久化使用 MySQL；服务端后台负责行军和自动刷野，因此关闭浏览器不会暂停任务。

## 当前可用

- 固定单玩家、无登录；普通建筑和科技视为全满。
- 英雄酒馆与技能书酒馆：服务端加权抽取、刷新扣费、请求幂等、候选快照、招募入库。
- 英雄、技能、卡池权重管理；配置均来自数据库。
- 据点、野地、副本、系统城、随机城池地图。
- 普通行军、自动刷野、后台结算、资源奖励和战报。
- 9种作战／运输兵种、6种城防；独立近远攻防、移动速度、负重，混编与纯士兵出征、真实损兵及返城。
- 军营招募／城防营造两条独立生产队列，逐个完成、离线补算、管理员时间加速；`/admin#military`管理数值、价格和耗时。
- 驻城与出征军粮按游戏时间消耗，训练完成才开始耗粮；缺粮只提醒，不损兵、不欠账。`/admin#controls`可添加六类资源，七日内重试防重复到账。
- 官方英雄图鉴头像与自定义英雄头像、44 种技能的独立大小图标；图鉴与状态全中文。
- 章邯、稀有六星神珊珊、三星蒙恬与王贲；神珊珊属性为按记忆定制。
- 英雄技能学习、升级、直接替换；出征触发判定及技能效果战报。
- 星级/天赋成长、升级预览；十三个装备槽、两个宝物槽、天赋水、统一物品与随机掉落池；装备实例支持精炼、打孔、镶嵌。
- 头像侧栏武将详情；六星四技能、五星三技能、其余两技能；七档品质边框。
- 流放/斩首（点击直接执行、装备退仓）、消耗改名卡改名；紧凑英雄界面、游戏式弹窗与右键穿戴／卸下。
- 五系原版宝石各1–8级、40张原图、四合一与批量合成；金刚双防，依部位镶嵌，旧宝石存档保留。
- 酒馆三类刷新记录开关：关闭时当前候选仅存内存，余额与领取仍存档；原表和历史保留。
- 行军与返城显示、头像点选出征；在册英雄最多6位。
- 普通任务返城后删除；自动出征记录保留，主动战报实时更新且最多50条，被攻击战报永久保留。
- 据点最高20级，等级越高防御和掉率越高；每次攻击降一级，0级消失。
- “我的物品”图标包裹：装备、技能书、宝物、消耗品，悬停查看详细说明。
- “藏宝阁”混合展示装备与宝物，与后台物品目录自动同步；英雄详情的装备、宝物、技能书及培养材料同样采用图标选择。
- 管理员时间倍率、跳时和动态地图刷新。
- 独立 `/admin` 管理入口；`/admin#tasks` 提供外部调度URL、说明、GET示例与最近成功状态，不内置周期调度器。
- 所有未考证数据以 `ESTIMATED` 或 `DIY` 标记，避免伪装成 2012 原始数值。

## 数据库纪律

唯一、完整、无业务数据的结构基线是 [`database/schema.sql`](database/schema.sql)。任何表或字段变更必须同时更新此文件及 `database/migrations/`。运行时配置强制要求 `DB_NAME=fenghuo`，服务连接后还会执行 `SELECT DATABASE()` 二次确认；脚本不会列出其他数据库。

开发数据位于 `database/seeds/0001_demo_catalog.sql`，与结构文件分离。

## 本地运行

### 一键启停（已配置好数据库和依赖）

macOS 在游戏文件夹中双击 **`游戏启动器.command`**，显示原生弹窗菜单：启动游戏、关闭游戏、重启游戏、查看状态。主脚本是同目录的 **`游戏启动器.sh`**；`.command` 仅是方便 Finder 双击的入口。

也可以在游戏文件夹的终端运行：

```bash
bash 游戏启动器.sh          # 可视化菜单；非 macOS 使用终端数字菜单
bash 游戏启动器.sh start    # 启动；已正常运行时不会重复启动
bash 游戏启动器.sh stop     # 关闭本项目的前后端
bash 游戏启动器.sh restart  # 重启
bash 游戏启动器.sh status   # 检查前后端、数据库连接与端口
```

- 启动器使用已有 Node.js（22.12 或更新版本）、`.env` 和 `node_modules`，不安装依赖、不改数据库结构、不重置存档、不启停 MySQL。
- 本地前端 `http://localhost:5173/`，管理后台 `http://localhost:5173/admin`；后端端口为 `18770`。保持开发模式热更新，便于边修改边测试。
- 不自动打开浏览器；关闭菜单、终端或浏览器不会停止游戏。需在菜单中选择“关闭游戏”才会停止服务。
- 关闭游戏后，调度 URL 暂时不可访问，行军与自动出征在下次启动后继续处理到期任务；关闭浏览器则照常实时结算。
- 日志和进程状态仅保存在游戏目录 `.runtime/`，已排除提交。启动时日志超过 2 MB 会轮换，保留上一次日志。
- 会识别本目录原先 `npm run dev` 启动的服务。端口被其他程序占用时提示冲突，不按端口直接强杀其他程序。

### 首次安装与手动运行

```bash
npm install
npm run db:verify-scope
npm run db:apply
npm run db:seed
npm run db:update
npm run dev
```

开发页面为 `http://本机地址:5173`。生产构建和质量门：

```bash
npm run check
npm start
```

构建后的服务监听 `18770`，同时提供网页和 `/api`。`.env` 含本机私密配置并已加入 `.gitignore`，不得提交或复制到公开位置。

已有存档升级只运行 `npm run db:update`，不要重新运行 `db:seed`（初始种子会覆盖目录配置）。所有内容更新均有版本记录，重复执行跳过。本命令按顺序应用技能学习、培养物品、官方技能品质、世界规则、调度任务、装备实例、藏宝阁、军事队列、管理员资源、军粮、酒馆藏宝阁和英雄宝石更新。单独补相应内容可运行 `db:update:treasury`、`db:update:military`、`db:update:resources`、`db:update:upkeep`、`db:update:tavern`、`db:update:hero-gems`（均加`npm run`）。结构变动已同步到完整无数据文件 `database/schema.sql`。

后续更新也已纳入完整命令：野地宝石（`db:update:wild-gems`）、据点宝石掉率与数量（`db:update:outpost-gems`）、装备属性校准与高级精炼石（`db:update:equipment-calibration`）。工坊“批量分解”只处理包裹装备，点击分解后直接删除所选装备并发放精炼材料；穿戴中或镶有宝石的装备会被拦截。套装修复及十件加成更新：`npm run db:update:equipment-sets`，按实际槽位计件（左右饰品各一件），同套十件主题属性加成25%，只取最高档。数值校准边界见 `docs/official-equipment-research.md`。

世界首领更新：`npm run db:update:world-boss`（完整更新已包含）。据点或野地刷新默认20%概率额外出现200级首领，首杀或游戏时间5分钟到期消失，地图显示倒计时；后台可独立调节等级与近远防御（新生成首领生效）。上架物品独立高概率批量掉落，宝石仅掉各系一级且每系数量独立随机；后台“城主控制台 → 世界首领”调整参数。普通地图刷新改为投影间距检查与随机分散布局，保留在途目标、现存首领与未选择的类型，修复新目标挤在角落的问题。详见 `docs/world-boss.md`。

显式开启实库回滚联调：`RUN_DB_TESTS=1 npm test -- tests/game-db.integration.test.ts`。只访问 fenghuo；所有测试业务写入在外层事务中回滚，不删除存档。

手动清理废弃道具：`npm run db:cleanup:obsolete`。仅移除六种旧无等级宝石及未实现用途的合成神石库存，停用来源并保存管理审计恢复数据；正常五系八级宝石与培养材料保留。检测到旧宝石仍镶嵌时整体拒绝，不破坏装备。此维护不随启动或完整更新自动执行，详见 `docs/obsolete-items.md`。

## 192.168.3.110 一键 Docker 部署

在110服务器终端执行（填入现有数据库密码）：

```bash
curl -fsSL https://raw.githubusercontent.com/gaara-xu/fenghuo/main/scripts/install-docker.sh | DB_PASSWORD='你的数据库密码' bash
```

默认部署到 `/gaara/fenghuo`，访问 **http://192.168.3.110:5173/**，后台 **http://192.168.3.110:5173/admin**。只启动游戏容器，连接同机现有MySQL `192.168.3.110:3306/fenghuo`，不创建MySQL容器、不初始化或清空存档；无需Nginx。重复执行可更新部署，本地密码配置 `.env.docker` 保留。首次切换前请关闭Mac上的本地游戏服务，避免两套进程使用同一个单人存档。

环境要求、日常启停、健康检查及故障处理见 [Docker部署说明](docs/docker-deployment.md)。

## 当前规则口径

- 酒馆新增[藏宝阁抽取](docs/tavern-treasure.md)：默认 8,000 金、三选一，装备宝物道具直接入包，后台可管理费用和权重。
- 前后台入口与外部定时调用见 [管理后台与调度接口](docs/admin-scheduler.md)。无新增登录，仅供受信内网；调度接口可选择配置独立Bearer令牌。
- 最新变化见 [世界与包裹更新](docs/world-inventory-update.md)，任务保留、据点等级、包裹与英雄上限以此为准。
- 目标是 2012 年末体验，而非现行版本。
- 技能最高10级；按用户自定义，六星初始/5/10/15级四槽、五星5/10/15级三槽、其余5/15级两槽。每场每方最多触发4个技能。
- 当前抽取权重只是可玩的估算值，不声称是腾讯原始概率；管理台调整后卡池版本会递增。刷新记录开关关闭时，新结果只存在内存，原历史不删除；游戏服务重启丢弃内存候选。
- 神珊珊默认权重 1，章邯 10。概率按当前启用权重计算，管理台可看单个候选位概率、编辑权重；无保底。新加入英雄仍需在管理台加入卡池。
- 依据腾讯官方页校正44个技能：腐蚀/穿刺在进攻时降低相应防御；缴械在防守时降低敌方近攻。已接入普通兵种和NPC城池工事目标；俘虏、密库等不适用的技能明确记录原因。
- 军事规则及资料边界见[兵种与城防更新](docs/military-update.md)。满科技暂按基础攻防 +100% 适配；技能按加法叠加。生产价格／耗时、城防数值、伤亡曲线和地图速度换算仍为单机可调值。
- 最新英雄、原版宝石、地图和交互说明见 [英雄宝石界面更新](docs/hero-gems-interface.md)。此前图片说明见 [藏宝阁与技能图标](docs/treasury-skill-icons.md)，装备规则来源见 [官方装备考证](docs/official-equipment-research.md)。37 张生成技能图、44 个技能大小图已接入；本轮地图使用腾讯旧说明页公开原图元素，不使用此前未授权的生成地图图片。
- 早期记录见 [此前内容说明](docs/hero-skill-update.md)，其中与本轮冲突的规则以培养更新为准。原创生成图像及提示词清单位于 `public/art/manifest.json`，不是官方素材。
