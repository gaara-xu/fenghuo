## 已接入

- 26 位英雄名字与头像，其中已有英雄保留原属性及个人进度，按图鉴修正星级；神珊珊和其他自定义英雄保留。
- 165 件装备：套装名与散件名直接来自官网，套装部件按图标及截图中的“头盔、肩铠、胸铠、护腿、战靴、项链、手镯、戒指”命名。
- 13 个装备槽；保留现有两个单机宝物槽。手镯/戒指允许两件同款，套装按实际穿戴槽位计数，左右各一件；重复同一槽位记录不额外计数。
- 独立实例存储，首次穿戴从堆叠库存转换；卸装、换装、流放后保留精炼级别、孔位、宝石。旧穿戴记录迁移为实例，不改物品数量。
- 精炼 +0—+9（装备显示1—10级）、打孔最多3孔、镶嵌。装备和宝物均可精炼，只有装备可打孔镶嵌。
- 固定装备数值先加到英雄成长属性，再计算百分比装备/套装加成；宝石不额外受精炼倍率加成。战斗、面板、升级预览、负重、行军均读取同一属性计算。
- 据点等级分档掉落三星/四星/五星装备，副本装备池及培养材料池可在 `/admin` 管理。
- 后台可调整属性、实力门槛、初始孔数、精炼成长、宝石数值、套装档位、精炼与打孔概率。
- 操作锁定英雄、实例、库存；出征中不能培养；UUID 幂等防重复消费；保留七天去重记录。

## 未取得原表的配置，不是官方数值

所有下列内容在目录元数据标为 `ESTIMATED` 或 `DIY`，只在后台和本文件说明，不把考证旁白塞入技能/装备游戏说明。

- 新增英雄暂用统一的六星基础参数；官网只有形象和姓名，不能据此推断战斗属性。已有英雄基础属性不覆盖。
- `0019` 将165件官方图鉴装备从统一的90/280/700占位值改为按部位、攻防类型、星级与套装定位校准。上述攻略有数值的条目作为参考，其余部件与星级比例仍是单机估算；整批仍标记 `ESTIMATED`。巡天曜日旗暂以近防、远防各3000为基础，默认线性成长下+9各8400；这不是已考证的原版+9表。每次精炼默认增加初始值的20%，旧宝物默认增幅15%。后台可为单件启用+0至+9的10项倍率表，统一用于实际战斗、英雄面板和物品说明；宝石不随精炼倍率放大。
- 装备实力门槛目前为星级×5＋1；“英雄实力＝星级×5＋等级”的公式有原文支持，但每件装备的要求没有完整原表。
- 新套装默认3/5/8/10件给主题属性5%/9%/15%/25%，左右手镯、戒指各算一件，只取最高档，不把25%叠加到低档。这是单机规则，十件25%按用户要求新增。官网截图个别魔怒效果与网络转载的4/7/10件版本不一致，因此没有把这些转载拼成2012官方全表。
- 精炼成功率依次100/90/80/70/60/50/40/30/20%；神石额外15个百分点；失败后35%降一级。打第一/二/三孔80/50/25%。均可改，不是考证概率。
- 后续已接入五系八级原版宝石、原图与相容部位，详见 `docs/hero-gems-interface.md`。早期自定义宝石保留库存但不再新掉落。
- 图鉴五星装备为橙黄，四星蓝紫，三星蓝；沿用用户自定义七品质展示顺序，不声称等于旧版五品质系统。
- 已确认截图里存在10级装备，但该专题未写完整装备等级上限；本次以截图所见1—10级实现，不声称已核实后续版本上限。

## 明确未实现的部分

此装备图鉴不是旧版宝物全图鉴。宝物原始名称/图标仍缺来源，现有单机宝物名称没有冒充原版。宝物合成、副属性随机继承、合成天工神石尚未实现。后续已实现免费取石和批量分解：每件产出“星级＋精炼级”的精炼石，另有10%独立概率产出一枚高级精炼石；高级精炼石使本次精炼成功率提高10个百分点。这些产量与概率是单机规则，不是查证的原版表。

验证：`npm run check`；`RUN_DB_TESTS=1 npm test -- tests/game-db.integration.test.ts`。实库测试每例都处于外层事务内，最终回滚，不保留测试英雄或测试装备。
