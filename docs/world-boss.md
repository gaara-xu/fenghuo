# 世界首领与地图散布

世界首领是按用户要求新增的单机玩法，不声称为2012年原版机制。

## 刷新和战斗

- 刷新据点或野地时额外判定一次，默认20%概率生成一只世界首领。管理后台手动刷新全部地图、GET据点任务、GET野地任务和GET全地图任务共用同一逻辑；全地图刷新也只判定一次，单独刷新随机城池不抽取首领。
- 同时最多一只未过期、未击败的首领，已经出现的首领不会被普通刷新覆盖或移动。过期或击败后可以再次刷新抽取，旧节点只为在途队伍保留坐标，全部返城后删除。没有空位时跳过生成，已有首领不会叠放或挤走其他目标。
- 每只首领固定存活300秒游戏时间，倒计时写入数据库；刷新、重复调度、服务重启、战败或修改后台配置都不会续时。管理员加速或跳转游戏时钟同步作用于期限。升级前没有期限的首领在首次后台维护时获一次5分钟期限。
- 地图及出征面板显示倒计时，到期立即隐藏目标；后端后台维护不依赖浏览器，关闭网页仍会清理。到期后抵达（含恰好到期）不战斗、不掉落、不损兵，按原行程空返。离线期间在期限内已抵达的战斗依旧正常结算。
- 默认200级，近防、远防各4,000,100,000，默认值按据点公式 `500 × (等级³＋等级)` 外推。后台可独立设置等级1–1000、近防与远防各1–1,000,000,000,000。修改仅影响之后生成的首领：每只生成时保存强度快照，地图说明、实际战斗及战败后均使用该快照；等级不会自动重算手工设置的双防。
- 只允许普通出征，可派英雄、士兵或混编。自动刷野排除首领，避免普通野地任务误派低战力部队。胜利一次立即从可攻击地图消失；败战保持生成时等级及原防御，不可靠失败磨到低级。
- 战斗事务锁定目标，首杀发奖与耗尽标记一并提交；同时到达的后续队伍空返，不重复掉落。返城前保留目标坐标以展示路线，全部返城后清理节点记录。

## 豪华掉落

每次首杀，对物品目录中每种已上架物品独立判定，默认掉率80%。新加物品自动参与；停用、回收物品不掉落，技能书要求对应技能也上架。不将英雄作为物品掉落，不影响酒馆英雄稀有度。宝石仅让每一种一级宝石参与，五系分别判定掉落、分别随机数量，不是从五系只抽一种；二至八级以及旧无等级宝石不参与。普通目标原掉落池与爆率不变。

| 类别 | 每种物品掉落数量（均匀随机，含两端） |
| --- | --- |
| 装备、宝物 | 5–20 |
| 技能书 | 20–100 |
| 消耗品 | 50–200 |
| 各系一级宝石 | 1,000–10,000（每系独立随机） |
| 其他材料 | 100–1,000 |

装备与宝物以未培养堆叠物品入包；技能书实际写入技能书库存，其他物品写入包裹。战报数量与入库一致，不只是显示倍率。沿用现有规则：资源受负重限制，道具掉落不受资源负重限制。

`/admin` → 城主控制台 → 世界首领，可改等级、近防、远防、刷新开关、出现概率、逐物品掉率及各类数量。数量可设1–100,000，非法或反向范围拒绝保存。关闭仅停止后续生成，不删除已出现的首领；已有首领使用战斗结算时的掉落配置，强度和期限保持生成时快照。

## 调度地址

沿用现有GET接口，不新增独立定时器：

- `/api/admin/tasks/refresh-wilds/run`：刷新野地并抽取首领。
- `/api/admin/tasks/refresh-outposts/run`：刷新据点并抽取首领。
- `/api/admin/tasks/refresh-map/run`：刷新全部动态目标并抽取首领。

可附 `?requestId=本次任务唯一编号` 防止调度重试重复刷新。同一编号不会重新抽取首领。任务地址及说明继续出现在后台“定时任务接口”。

## 地图聚集修复

旧逻辑从同一角落按6坐标间距扫描，占用不同数据库坐标的图标也可能重叠。现在使用等距投影后的屏幕距离，避开主城和其他目标，优先选择空旷区域，再从这些候选中随机选点。刷新时未被行军引用的普通动态目标也重新分散，不只是新目标变位置。

保留正在出征或返城引用的目标、现存首领及未被本次任务选中的目标。位置交换在同一事务内完成，失败全部回滚；坐标不足时不覆盖旧目标。常驻标签只显示名称、等级，坐标在悬停或选中时显示，悬停说明始终提供完整坐标。

## 存储与更新

`npm run db:update:world-boss`（完整 `db:update` 也包含），版本 `0020_world_boss`。只初始化 `game_settings.world_boss_rules`，不重置存档、不发物品、不强制刷新现有地图；重复执行保留管理员修改。

首领复用 `map_nodes.node_type=WILD`，通过 `garrison_config.worldBoss=true` 区分；前台获得独立 `worldBoss` 标志与 `expiresGameAt`。强度配置新增 `level`、`meleeDefense`、`rangedDefense`，旧配置读取时补默认值，保存时一并写入；节点JSON新增 `meleeDefense`、`rangedDefense`、`expiresGameAt`（UTC ISO游戏时间）。无需DDL或额外迁移命令，JSON字段、配置和清理规则已同步到 `database/schema.sql`。
