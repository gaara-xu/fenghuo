# 英雄、技能与美术更新

## 武将与稀缺性

新增章邯、神珊珊、蒙恬、王贲。当前共 11 位，全部有独立生成头像。

章邯采用后期网络表列出的近攻 2187、远攻 0、双防 4375、速度 5000、负重 50000。原表没有说明英雄等级与天赋口径，因此标为“待核实”，不声称精确原版基础值。来源：[六星属性转载表](https://www.9game.cn/news/8616479.html)。

“神珊珊”名称可见于[玩家讨论转载](https://www.9game.cn/news/9278159.html)，但没有可靠属性表。按城主记忆定制：六星，近攻/远攻各 35000，近防/远防各 40000，速度 4900，负重 100000，体力 150。明确标为“自定义”，不是复原出的官方数值。

英雄卡池初始权重：神珊珊 1，章邯 10，蒙恬/王贲各 150；已有英雄权重保留。神珊珊最低，无保底。每个候选位独立抽取，单候选概率为该条目权重 / 全部启用条目权重之和。管理员可修改，不硬编码永久限制。

其他已存在英雄数值未擅自覆盖；蒙恬和王贲的具体数值仍是单机估算。

## 技能

[2012 年技能玩法资料](https://www.doyo.cn/article/52737)记载技能学习、升级、槽位规则；[2012 年战斗计算示例](https://jingyan.baidu.com/article/f71d60375c87401ab641d139.html)说明攻击加成按加法、学院涉及科技加成。参考满级触发与效果来自[玩家整理](https://www.juduo.cc/club/4318502.html)，并非官方完整数据表。

- 初学 0 级、最高 10 级；学习耗一本书。升级耗同名技能书及剩余英雄经验。
- 普通英雄 5/15 级开放两槽，六星初始/5/15 级开放三槽。
- 每方至多四个技能成功触发，同名技能只判定一次。
- 热血加近攻，精准加远攻，狂热加全攻，学院加科技攻击加成。
- 腐蚀削弱敌方近攻、穿刺削弱敌方远攻、缴械削弱敌方全攻；只有防守时适用。
- 每次出征均从数据库加载已学习技能，自动刷野复用同一战斗结算。战报保存触发与未触发原因、基础/技能后/敌方战力。

当前只是单英雄战斗适配，不是原版兵种编队。兵种目标被映射到英雄攻击通道。防守技能的结算函数已实现，但正常玩法尚无守城战入口。技能低等级成长、升级经验、英雄升级经验、科技百分比为估算配置，后续可校准。

## 数据与美术

完整无业务数据结构文件：`database/schema.sql`。本次唯一结构变动是技能初始等级默认值为 0，迁移文件同步保存。

升级用 `scripts/update-game.ts`，只有 fenghuo 连接，结构迁移可重入，内容修改与版本记录放在同一事务。没有重置玩家资源、已招募英雄、技能书或战报。

美术通过 imagegen 生成：11 张武将、7 张技能图标，仿旧页游风格的原创插画，非腾讯原图。素材路径和提示词见 `public/art/manifest.json`。未来在后台新建英雄可选择现有头像，后续再补专属新图。
