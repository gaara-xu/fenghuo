# 培养、物品与界面更新

## 已接入

- 武将页：头像名册、单将详情、八件装备及两个宝物槽、技能修习、升级预览、改名与天赋洗练。选择状态保存在当前浏览器会话；轮询不重置选将。
- 技能选择使用自绘选单，展开后显示图标与说明；支持方向键、回车、Esc，空间不足时向上展开。其他原生控件有统一暗色样式。
- 品质独立于星级：1 白、2 蓝、3 黄、4 绿、5 蓝紫、6 橙黄、7 红。红色发光，尊重系统减少动画设置；管理台可调整。
- 天赋水使用幂等请求、事务扣除。随机可降档或不变；不改变等级，按新天赋重新计算已有等级属性。
- 英雄、技能均有成长预览；详情与战斗共用派生属性。速度参与行军，四类资源搬运受负重限制，金币和道具不占资源负重。
- 八件青铜装备、六种一星属性宝物、天赋水、体力药、经验书及材料目录。装备、宝物可穿戴、卸下；旧版精炼/合成材料保留但对应加工流程尚未实现。
- 物品管理统一目录与库存，现有技能书自动映射到目录，库存不重复存储；可选择掉落项、权重、概率、次数、数量与等级范围。普通及自动据点胜利共用掉落逻辑。
- 流放、斩首点击直接执行，后端仍校验目标名字与身份，拒绝在途武将；装备宝物退仓，所学技能移除。武将逻辑移除、保留历史引用，不会破坏历史行军。交易入口保留且禁用。
- 行军显示路线、头像、剩余时间及返城状态；自动刷野显示目标驻扎标识。地图刷新不删除历史节点，不改动在途目的地。
- 战报静默轮询，新报通过计数提示进入；可手动清空，数据库仅留最新50条，超额永久删除。奖励不会因删除战报而丢失。

## 官方资料与适配边界

[腾讯官方英雄技能表](https://zg.qq.com/webplat/info/173/641/1365/201012/85358.shtml) 列出44项10级技能效果，均已入库；其中领悟在该页标为当时未开放，默认停用。腐蚀/穿刺已改为进攻降低相应防御，缴械改为防守降低近攻。

官网只给10级效果，没有完整0—9级、经验曲线或品质分档；这些数值采用可调整估算。每场每方最多发动4个，同名去重、战力技能优先、辅助技能后判定，家族战场无效。

技能槽按用户自定义而非该官方页：六星在初始/5/10/15级依次解锁4槽；五星在5/10/15级解锁3槽；其余5/15级解锁2槽。

[2012年天赋介绍](https://jingyan.baidu.com/article/64d05a0298112dde55f73bab.html) 可支持星级与天赋影响成长的机制，但无法确定逐级公式。当前公式为估算：战斗属性乘数为1+(等级²−1)×成长系数×星级系数×天赋系数；负重线性增长，速度默认固定。旧库定义数值视为一级基础，没有重置或覆盖玩家的英雄基础配置。

目前仍是单英雄战斗适配，兵种类效果作用于此英雄对应攻击通道；并非完整多人兵种战。城防、家族、文韬武略、俘虏、伤亡、密库等技能均入目录并有条件分支，但当前世界没有相关数据时会明确显示不适用，不伪造触发。完整兵种、俘虏、守城子系统不在本轮完成范围内。

## 图片

沿用工作区已有11张武将头像与7张技能图标。用户选择“先完成代码，不允许复制本轮生成图片”，因此未复制6张已生成地图素材，未继续生成37项新增技能的图片。缺图位显示名称与“待配图”，不冒用其他技能图片。大小图标采用同一原画的组件尺寸（42/62/156像素），未来接入后保持一致。

待生成技能的独立构图描述保存在 shared/skill-catalog.ts 每项最后一列；本轮地图使用内置生成工具完成原画但未接入项目。地图当前是程序布局预览，不是最终还原美术。

## 更新和验证

完整结构总文件：database/schema.sql，无业务数据，包含所有表、字段与本轮新增JSON字段设计。增量结构见0003_items、0004_hero_retirement、0005_quality；培养种子与技能更新不清除玩家存档。

已有数据库运行 npm run db:update，版本记录保证重复执行不覆盖配置；首次初始化按README创建结构/种子后也需执行此命令。0003版本包含0004退役字段迁移。

本轮 npm run check 通过；39项单元测试通过，13项实库测试在外层事务中回滚，包括技能、成长、掉落、装备、天赋、移除、战报与结构总文件一致性。真实清理行为只来自已启用的最新50条保留策略或用户手动清空，不来自测试。
