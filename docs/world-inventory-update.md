# 世界与包裹更新（2026-09-15）

## 任务和战报

- 普通出征/侦察：只保留在途数据；返城或取消后物理删除数据库记录。战报外键自动置空，不丢失最新战报。
- 自动出征：任务记录保留；被攻击战报使用 `battle_reports.direction=INCOMING`，永久保留，按20条游标分页读取。
- 主动出征战报最多50条，超出物理删除；“清空出征战报”不会删除被攻击记录。被攻击记录尚无自然生产入口，本轮未新增虚拟玩家袭城。
- 页面每2秒直接更新战报，无“新战报待查看”按钮。已有展开状态通过稳定编号保留，阅读时尽量锚定当前战报位置。
- 主动战报默认筛选“有物品掉落”，只显示至少一项正数量物品掉落的记录；单纯粮食、金币等资源收益不算物品。游戏式按钮可切换“全部战报”，轮询不会重置当前选择。筛选只影响显示，不改变50条存储上限或清空范围；被攻击记录仍全部可见、永久保留。

## 据点与目标消耗（单机自定义规则）

- 最高20级；战力为 `500 × (等级³ + 等级)`，1级1000，10级505000，20级4010000。
- 获胜才掉落；掉落池成功概率为 `管理基础概率 × [0.25 + 0.75 × (等级−1) / 19]`。池中权重、抽取次数、数量、启用开关不变。
- 本轮战斗使用攻击前等级计算守军、经验和掉落，之后不论胜败降1级；守军也随新等级下降。
- 据点、野地、副本、系统城和随机城统一每战降1级，胜败都生效。非据点守军按剩余等级同比减弱，不改变后台原始战力标定；据点仍使用上述等级公式。
- 0级即从地图移除；若有其他队伍已经向该目标出发，则空返、不制造战报或额外收益。等所有队伍返城后物理删除耗尽目标记录。副本、系统城仍不参与现有动态刷新，因此耗尽后不会自行重生。
- 同一事务内锁定目标和任务，重复处理不会重复降级、发经验或道具。刷新地图保留在途目标；新据点随机1—20级。刷新权重调整为1—5级合计5%、6—10级10%、11—15级25%、16—20级60%，每档内各级等概率，20级单独占12%。这是单机配置，不代表原版概率。
- 权重统一维护在 `shared/world-rules.ts` 的 `OUTPOST_LEVEL_WEIGHTS`，后台手动刷新及外部调度刷新共用；从下次刷新起生效，不直接改现有地图、在途目标、守军公式或物品掉率。野地和随机城池仍为1—5级等概率。
- 自动十次锁定点击的目标，即使目标降到原选定等级之外也继续攻击；不擅自更换目标。老任务未记录目标的，首次启动按原等级范围选择一个目标后锁定。
- 一轮为真实出发、抵达战斗、返城；返城才扣一次剩余次数。每轮按距离和当前幸存编队最慢速度计算，不存在固定60秒瞬时攻击分支。10轮未完成但目标已耗尽或纯士兵全灭则提前结束，保留原因；暂停时已出发队伍正常返城。
- 离线按每次出发/抵达/返城的时间顺序补结算，重试不重复扣级、计次或发奖励。旧在途任务通过行军快照版本兼容，避免已经在出发时扣过次数的旧行军返城再次扣除。
- JSON扩展字段及次数语义同步于 `database/schema.sql`，无需新增列或执行数据迁移，不追溯改写旧战报。
