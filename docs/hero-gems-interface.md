# 英雄、宝石与交互更新

## 使用入口

- 我的英雄：紧凑头像侧栏、装备人偶和右侧操作面板并排，英雄区与操作区比例 7:3；星级只显示已获得的实心星。
- 右侧默认显示属性成长、当前装备加成及随身道具，不再显示天赋水库存与天赋概率大块文案。当前装备加成包含固定属性、宝石与百分比效果，套装显示当前件数与各档状态：生效为彩色，未激活或被高档替代为灰色。沿用现有只取最高档规则，不额外叠加3/5/8/10档。套装按实际穿戴槽位计数，左右手镯、戒指各算一件，十件档为该套装主题属性25%。点击装备槽切换行装和工坊，点击技能槽切换技能操作；点击头像或“返回属性”回到默认页，不再保留底部独立操作区。
- 英雄身上的装备与宝物图标右下角显示+0至+9，与包裹、工坊保持一致；穿戴装备悬停说明中的套装颜色与实际效果一致。移除界面底部误显示的“正在点燃烽火…”文字。
- 点击非完美的天赋文字，直接消耗一瓶天赋水，不再二次确认；完美天赋文字不响应点击。包裹或随身道具中主动使用天赋水仍可重洗完美天赋，不弹确认窗，可能降低。
- 点击英雄名字：游戏式改名窗口，每次消耗一张改名卡。取消、空名、相同名字不消耗；重试不重复扣卡。不再显示名字下方的改名提示、卡数量、原名，也不提供恢复原名和英雄交易占位行。
- 顶部“工坊”：独立入口，左侧图标选装备（包裹／英雄身上），右侧打孔、镶嵌、免费取石；切换“宝石合成”处理五系八级宝石。我的物品中的宝石工坊按钮也进入这里。
- 工坊可直接加工包裹中的装备，无需先穿戴；同名物品按独立实例选择。未培养堆叠装备首次加工仅分离一件，剩余数量不变，操作后自动选中新实例。
- 取石无需道具或金币，选中的一颗宝石完整退回包裹，装备孔数、精炼、其他宝石不变；英雄属性立即扣回该颗宝石的加成。出征英雄的装备不可操作，已换装的旧请求不能误加工替换后的装备。重复请求不重复返还。
- 四颗同类同级宝石合成下一等级一颗，可批量合成；八级封顶。原有精炼、打孔的可调概率保持不变，打孔仍消耗天工神石，镶嵌消耗所选宝石。英雄详情中的装备工坊保留，也支持免费取石。
- 工坊新增“批量分解”：图标多选、搜索、品质筛选、堆叠数量输入与一键选择可见未精炼装备。高精炼装备需要手动选择；侧栏列出装备、等级、数量和材料收益，点击分解直接执行，不再弹确认框。每件必得“星级＋精炼级”枚精炼石，另有10%概率获得一枚高级精炼石（单机设定）。每批最多100条、1000件。穿戴中、镶有宝石、已停用或非装备物品不可分解；缺货或任一项目失效会整批回滚。先取石再分解，宝石不会被误删。分解会永久删除所选实例或扣减堆叠数量，精炼与孔位不返还；UUID重试不重复消费或重复发奖。
- 装备、宝物、技能书、培养材料：悬停查看完整属性，离开原图标立即收起；浮层不接收鼠标，也不会因移入说明而保留。鼠标留在图标上用滚轮，或聚焦图标按 PageUp／PageDown，可翻阅长说明；Esc 收起。在装备候选上右键可直接穿戴，已穿戴部位右键卸下。流放／斩首、分解、清战报和后台物品下架同样直接执行，不加确认；风险说明留在界面或悬停说明里。
- 我的物品：点击天赋水、经验书或体力道具，多英雄时点选待命英雄即使用，只有一位英雄时直接使用；关闭英雄选择窗口不消耗，出征英雄不能使用。随身道具直接作用于当前英雄。
- 天下：原版城池、营寨、地形图元素与菱形地块；显示真实行军和返城路线。点击或右键目标进入调兵窗口，可选英雄或纯士兵出征。修复拖动地图后无法点击目标的状态问题。

网页不再有二次确认框，仍保留改名等必要输入窗口，全部使用游戏皮肤；输入校验错误与缺材料提示不阻塞操作。桌面启停脚本仍使用系统菜单，与游戏内界面分开。

前台与后台的操作成功、报错、复制等临时提示统一最多显示1秒，到期清空，不以悬停或同文重复赋值续时；切换离开页面时取消计时。重试入口独立于错误横幅保留。必要输入窗口、持续状态数据、行内输入错误与物品悬停说明不自动限时关闭。

## 原版宝石

| 修罗 | 近攻 | 武器、手镯、项链、戒指 |

| 金刚 | 近防与远防 | 头盔、肩甲、胸铠、防具 |
| 疾风 | 速度 | 战靴、坐骑 |
| 巨象 | 负重 | 护腿 |

五系各 1–8 级的原始 GIF 已保存于 `public/art/official/item*.gif`，不依赖在线图床。金刚宝石同时增加两种防御。四合一不额外收取金币；当地单机没有绑定交易子系统，因此未增加原版绑定／未绑定合成分支。

新宝石进入据点、副本随机掉落池和酒馆藏宝阁；高等级据点可掉落较高等级宝石。掉落概率、品质颜色和刷新权重是本地配置，不冒充官方爆率。后台物品管理可修改名称、图标、系别、等级及属性，掉落池和卡池单独配置。

野地使用独立的“野地一级宝石”掉落池（`gem_wild`）：默认每次获胜抽取一组，五系一级宝石等权选择一种，数量为 1–1000 的等概率随机整数，包含两端。普通出征与自动出征共用；战报显示数量与实际入包一致，失败不掉落。其他目标的概率、数量与既有库存不变。在 `/admin` → 物品管理 → 随机掉落池中可调整概率、权重、数量及启停；数量上限前后端统一为1000。

据点宝石掉率调整（`0017_outpost_gem_rates`）：初、中、高三档宝石池的基础概率由12%、16%、20%统一提高到100%。仍乘以据点等级系数，实际胜利掉率为1级25%、10级约60.53%、20级100%。高级宝石的相对权重、掉落池启用状态不变，不影响其他物品或野地、副本掉落；败战仍不掉落。

据点宝石数量修正（`0018_outpost_gem_quantities`）：三档据点宝石池单次掉落由固定1颗改为 **1–1000颗等概率随机整数**，包含两端。普通出征与自动出征共用，实际发放数量与战报相同，不是单纯修改显示。保留原宝石等级与权重，只修改宝石条目的数量上下限，不改非宝石条目、其他池、既有库存和历史战报。注意地图“山贼据点”和“野地”不是同一种目标，现在两者的宝石数量范围均为1–1000。

旧自定义宝石、库存、已镶嵌快照全部保留，仅停止旧宝石的新掉落和抽取。旧快照仍按旧属性计算。

## 暂停的技能

血缘、藤甲、铁壁、火箭术、忠诚、威风、反间、流言对应的家族／科技技能暂时下架。现有书籍、已学习等级不删除，前台隐藏、战斗不启用；后台重新启用后恢复。一次性数据迁移不会反复覆盖管理员的上架选择。

## 结构与升级

完整设计仍是 `database/schema.sql`；`0015_hero_gems` 扩展 JSON 字段说明，并新增宝石、改名卡和技能启停初值。已有存档使用 `npm run db:update:hero-gems` 或完整 `npm run db:update`，不要重跑种子。

野地宝石池使用一次性配置更新 `0016_wild_gem_drops`，命令 `npm run db:update:wild-gems`（也已接入完整更新）。现有 smallint 字段已容纳1000，无需DDL。脚本只连接 `fenghuo`，事务内新增野地池与五个条目，重复执行不覆盖后台后续调整，不发放物品、不重置存档。

据点宝石更新命令为 `npm run db:update:outpost-gems`，也已接入完整更新。独立检查0017掉率与0018数量两个版本，已更新掉率的存档仍能获得数量修正；只改三个确切据点宝石池的对应配置，无DDL、不发奖、不重置存档。重复运行不覆盖之后的后台配置。

装备校准与高级精炼石使用 `npm run db:update:equipment-calibration`（0019），无新表。完整设计文件同步说明逐级倍率字段与分解操作结构。数值来源、推算边界及更新保留规则详见 `docs/official-equipment-research.md`。

功能测试覆盖改名卡扣除与幂等、四合一及批量合成、双防镶嵌、技能隐藏再上架、纯士兵出征返城、地图拖动后点击和右键选择、直接操作、防重复提交、改名输入校验和一秒非阻塞提示。
