# 征途装备首版

至尊套新增13件近远攻防+100%；15件近远攻防+200%、速度+50%、负重+100%，仅取最高档。至尊两件宝物计入套装，绿色及金色规则不变。独立执行 `node --import tsx scripts/update-supreme-set.ts` 同步现有定义，保留精炼、宝石与库存，不在代码更新流程执行。

三套各15件：武器、盾、胸铠、头盔、腰带、鞋、项链、双护腕、双戒指、肩铠、坐骑及两件宝物。腰带适配现有护腿槽位。肩铠和坐骑计入套装；绿色和金色宝物不计入且最高档为11件，至尊宝物计入并有15件终极档。
