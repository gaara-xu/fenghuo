三套各11件：武器、盾、胸铠、头盔、腰带、鞋、项链、双护腕、双戒指。腰带适配现有护腿槽位；肩铠、坐骑和宝物保留原有装备。

|套装|品质|3/5/8/10/11件近远攻防加成|
|---|---|---|
|完美的天魔|绿色|6% / 10% / 16% / 25% / 30%|
|卓越的天尊|紫色|9% / 15% / 24% / 35% / 45%|
|至尊的英雄|红色|12% / 20% / 32% / 45% / 60%|

同套装仅取已达到的最高档。精炼+0至+9、打孔及宝石使用现有系统。
这是跨游戏改编：装备本名与展示图片来自征途官网；品质配色、前缀组合、基础数值、分档效果由本项目设计，不声称是征途原始属性。参考征途灵魂锁链配装与卓越套装攻防收益，首版用按件数激活攻防加成实现，不包含未实现的伤害反射、忽视防御、人物血量或五行配对。
